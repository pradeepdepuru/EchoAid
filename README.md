# 🌟 EchoAid: Hear Their Stories, Fund Their Future

An empathetic, high-tech mutual aid portal developed for the **International Day of Charity Hackathon**. **EchoAid** bridges the gap between digital resource equity and human empathy by combining **hyper-realistic AI voice synthesis** with **frictionless, near-zero-fee Web3 micro-donations**.

---

## 💡 The Mission: Demarginalizing AI Education & Compute Infrastructure

In our current rapidly evolving AI landscape, access to computing power, edge rigs, and technology education is the ultimate differentiator for future success. Unfortunately, systemic geographical and financial barriers create an "AI divide." 

**EchoAid** gives grassroots communities and student cohorts a localized, global voice. By pairing human stories with digital equity, the portal provides a streamlined platform to fund:
* **AI Education & Training:** Equipping youth with the technical skillsets to build solutions closest to their communities.
* **Edge Rigs & Local Hardware:** Providing the mechanical infrastructure required to develop and execute AI workloads locally.
* **Compute Infrastructure:** Directing raw processing power and server availability to marginalized engineering hubs.

### Why Solana? ⚡
Traditional non-profit banking rails are plagued by slow verification times, geographic boundaries, and high cross-border transactional fees that bleed out small-scale donations. We selected the **Solana Blockchain** because it serves as an instantaneous, universal currency system. With **near-zero network fees** and **sub-second confirmation times**, it removes global friction completely—meaning a 0.05 SOL micro-grant from across the planet lands directly in a student's project wallet instantly.

## 🛠️ Tech Stack & Prize Category Integrations

EchoAid proudly incorporates advanced software configurations across multiple technical boundaries:

* **Frontend Sandbox:** `Next.js 15` built on top of `TypeScript`, custom `Tailwind CSS`, and `HTML5 video backgrounds`.
* **🔊 Best Use of ElevenLabs:** Implements serverless route handling integrated with ElevenLabs Developer APIs to securely parse dynamic textual storytelling into pristine human voice streams. 
* **🪙 Best Use of Solana:** Utilizes `@solana/web3.js` to anchor client-side transaction generation (`SystemProgram.transfer`), directing secure micro-grants across the Solana Devnet workspace.

## ⚙️ Local Development Installation

Follow these steps to run the EchoAid workspace locally on your computer:

### 1. Clone the Repository
```bash
git clone https://github.com
cd EchoAid
```

### 2. Configure Environment Variables
Create a file named `.env.local` inside the `echoaid-app` folder and input your private api keys securely:
```env
ELEVENLABS_API_KEY=your_elevenlabs_api_key_here
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run the Local Host Environment
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser window to verify the system sandbox locally!
